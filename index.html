grok-tasks

grok-tasks is a personal tool used only by its developer (Jun Funakata) to read his own Google Tasks and include them in a private daily summary.

Privacy Policy

This app requests read-only access to Google Tasks (https://www.googleapis.com/auth/tasks.readonly). Task data is used only to create the developer's own daily summary. It is not sold, shared with third parties, or used for advertising. Access can be revoked at any time from Google Account permissions.
